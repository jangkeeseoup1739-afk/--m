# 명결(命結) AI 사주 · 인생차트 플랫폼 기술 문서 및 아키텍처 로드맵

---

## 1. 시스템 개요 및 아키텍처 (System Overview)

명결(命結)은 생년월일시와 출생지를 기반으로 **사주명리학(四柱命理學)**, **음양오행(陰陽五行)**, **십성(十星)**, **십이운성(十二運星)**, **신살(神殺) 및 귀인**, **대운(大運)**, **10개년 세운(歲運)**과 더불어 **서양 점성술(10대 행성 및 하우스)**, **태국 수리야야트라 점성술(10행성 체계)**을 하나의 사용자 인터랙티브 라이프 차트로 융합한 개인화 AI 인생차트 플랫폼입니다.

```
[사용자 입력 (생년월일/시간/지역)]
          │
          ▼
[결정론적 사주/점성학 연산 엔진] ─── (오차 없는 순수 수학/천문 계산)
  ├─ SajuCalculator (율리우스력/절기/60간지/오행/십성/운성/신살/대운)
  ├─ AstrologyCalculator (황도12궁/10대 행성/하우스/ASC 추정)
  └─ ThaiAstrologyCalculator (수리야야트라 10행성/요일별 수호신)
          │
          ▼
[구조화된 정밀 명식 데이터셋 (JSON)]
          │
          ▼
[명결 13단계 정밀 리포트 엔진] ──── (전통 문헌 기반 체계적 합성)
          │
          ▼
[서버 사이드 Gemini 3.8 Flash 프록시] ── (심층 해석 및 1:1 대화형 상담)
          │
          ▼
[사용자 인터페이스 (SVG 만다라 + 13단계 대시보드 + 궁합 + AI상담)]
```

## 3. 외부 계산엔진 및 API 연결 계획 (연동 계획)

현재 자체 내장된 경량 수리 계산 모듈은 대부분의 사주 명식(1900~2100년)을 빠르고 안정적으로 계산합니다. 서비스 규모 확장 시 정밀도와 속도를 극대화하기 위해 다음과 같은 외부 엔진 연동 계획을 수립합니다.

### 3.1. 고정밀 한국천문연구원(KASI) 역법 API 연동
- **목적**: 24절기의 초(Second) 단위 입절 시각 및 한국 표준시(동경 127.5도 vs 135도 균시차) 완벽 보정.
- **연동 방식**:
  - 정부 공공데이터포털 천문역법정보 API (`getSpcifyLunCalInfo`)
  - 또는 오픈소스 고정밀 천체물리 라이브러리(`astronomy-engine` / `Swiss Ephemeris`) 백엔드 바인딩.
- **폴백(Fallback) 구조**: 외부 API 장애 시 내장된 수리 계산 엔진이 무중단 자동 대체(Graceful Degradation).

## 4. 데이터베이스 연동 및 캐싱 최적화 로드맵 (Database & Caching)

```
[클라이언트 요청]
       │
       ▼
 [API Gateway / Express Server]
       │
       ├─ [Redis / In-Memory LRU Cache] ── (동일 출생정보 캐시 적중 시 1ms 즉시 반환)
       │
       ▼
 [데이터베이스 (PostgreSQL / Cloud SQL)]
       ├─ Users (익명 사용자 세션 및 소셜 로그인 계정)
       ├─ LifeCharts (계산된 4기둥, 오행 점수, 십성 프로필 JSONB)
       ├─ Consultations (AI 대화 히스토리 및 질문 패턴)
       └─ CompatibilityRecords (궁합 분석 내역)
```

### 단계별 DB 구축 계획:
1. **Phase 1: 비회원 로컬스토리지 & 서버 인메모리 LRU 캐시 (현재 완료)**
   - 개인정보 저장 없이 브라우저 내 세션 보관.
   - 서버 측에는 API 호출 최적화를 위한 SHA-256(생년월일시) 기반 메모리 캐시 적용.
2. **Phase 2: PostgreSQL (Cloud SQL) 기반 영구 스토리지 연동**
   - 사용자 계정별 "가족/지인 사주 보관함" 기능 구축.
   - `life_charts` 테이블에 `chart_data JSONB` 및 GIN 인덱스를 적용하여 "특정 오행이 결핍된 사용자 집단", "특정 일간 사용자 통계" 등의 고속 쿼리 지원.
3. **Phase 3: 읽기 복제본(Read Replica) 및 파티셔닝**
   - 신년 시즌(12월~2월) 트래픽 폭증 대비 연도별/월별 읽기 분산 인프라 구성.

## 5. Gemini AI 호출 최적화 및 비용 절감 전략 (API Optimization)

AI API 호출 비용을 최소화하고 응답 지연(Latency)을 200ms 이하로 단축하기 위한 전략:

1. **데이터 전송 최소화 (Semantic Token Economy)**
   - 사주팔자 계산 자체를 AI에게 시키지 않고(토큰 낭비 및 환각 방지), 순수 수식으로 계산된 핵심 데이터만 구조화된 JSON 형태로 AI 프롬프트에 주입.
2. **계산 엔진과 해석 엔진의 명확한 역할 분리**
   - 사주팔자 글자, 오행 비율, 십이운성, 신살 목록 등 13단계 기본 리포트는 서버/클라이언트 정밀 지식 베이스에서 0ms로 즉시 렌더링.
   - 사용자가 추가 질문을 하거나 심층 AI 브리핑을 원할 때만 스트리밍(Streaming) 방식으로 지연 호출(Lazy Invocation).
3. **캐시 가능한 프롬프트 분리 (Context Caching)**
   - 명결의 고유 철학과 십성/오행 기본 가이드라인은 고정 시스템 인스트럭션으로 캐싱하고, 사용자별 가변 데이터(이름, 일간, 점수)만 델타로 전송.
4. **온디바이스/에지 폴백 보장**
   - API 키 미설정 또는 네트워크 단절 상태에서도 사용자가 13단계 프리미엄 분석 리포트를 100% 온전하게 열람할 수 있도록 설계된 무결점 폴백 엔진 내장.

## 6. 향후 비즈니스 및 유료화 확장 로드맵 (Roadmap)

- **v1.0 (현재)**: 무료 사주, 코스믹 만다라, 13단계 종합 분석, 2026~2035 연운, 서양/태국 점성술, 사주 궁합, AI 1:1 상담.
- **v1.5**: PDF 고해상도 인생차트 다운로드 및 카카오톡 공유 기능.
- **v2.0**: 전문가용 대운 세밀 조정 모듈 및 가족/지인 다중 차트 폴더 관리 기능.
- **v3.0**: B2B 파트너십 API (인사 채용 성향 분석, 기업 팀원 궁합 및 시너지 진단).
